# Life RPG

Мобильное RPG-приложение для саморазвития на Flutter: реальные дела превращаются в опыт, уровни, навыки и награды.

**Стек:** Flutter 3.27 / Dart 3.6, Riverpod, GoRouter, Hive (офлайн-хранилище), Supabase (аккаунт и синхронизация), fl_chart, flutter_local_notifications.

## Быстрый старт

```bash
flutter pub get
flutter run
```

Без настроенного Supabase приложение работает в **гостевом режиме**: все данные хранятся на устройстве, игра полностью доступна.

### Подключение Supabase (аккаунты и синхронизация)

1. Создайте проект на supabase.com.
2. Примените миграцию `supabase/migrations/20261113000000_init.sql` через SQL Editor или `supabase db push`.
3. В разделе *Authentication → URL Configuration* добавьте redirect URL `io.liferpg.app://login-callback` (для web — адрес сайта).
4. Скопируйте `env.example.json` в `env.json`, впишите URL проекта и **публичный** anon/publishable-ключ.
5. Запускайте с конфигурацией:

```bash
flutter run --dart-define-from-file=env.json
```

`env.json` добавлен в `.gitignore`. Service-role ключ в клиент не кладётся никогда: доступ к данным защищён RLS и серверными функциями.

## Что реализовано

| Раздел | Возможности |
|---|---|
| Персонаж | Создание в 5 шагов: имя, эмблема и цвет, пол/возраст (по желанию), класс, направления и цели, стартовые задания. Рамка аватара усложняется с уровнем (5/10/20/30). |
| Характеристики | 7 характеристик со своим уровнем и XP, история начислений, связанные задания, график за 30 дней, радар баланса. |
| XP и уровни | Формула `100 + L × 50` вынесена в `GameConfig`. XP — журнал транзакций, уровень вычисляется из суммы, ничего не обнуляется. Бонусы: серия (до +20%), фокус (+10%), навыки (до +15%), регулярность (+25% в «Дисциплину»), закрытый день (+25 XP). |
| Задания | Ежедневные (каждый день / по дням недели / каждые N дней), еженедельные, миссии с подзадачами, побочные, испытания с ежедневными отметками. Измеримые цели (страницы, шаги, минуты…), дедлайны, напоминания, длительность, пауза, архив, отмена выполнения в течение 24 часов. |
| Дерево навыков | 56 навыков в 7 ветках по 5 ярусов, масштабирование и перемещение пальцами, требования (уровень, предыдущие навыки, достижения), стоимость в очках навыков, анимация открытия. |
| Последствия | Отметка в журнале, потеря бонуса серии, восстановительное задание, провал миссии; потеря Gold и XP — только если включить. Восстановление: восстановительное задание, перенос, уважительная причина (лимит в месяц). Пропуск дня не стирает прогресс; после долгого отсутствия проверяются только последние 7 дней. |
| Серии | Текущая и лучшая серия, календарь активности, дни отдыха (до 2 в неделю), режим отпуска, заморозки (по желанию). |
| Gold и магазин | Свои награды, покупка с подтверждением, отмена покупки, история движения Gold. Дневные лимиты защищают от фарма. |
| Достижения | 21 достижение четырёх редкостей с прогрессом и наградами. |
| Аналитика | Фильтры: день / неделя / месяц / год / произвольный период. График XP с подсказками и табличным видом, календарь активности, задания по категориям, прогресс характеристик, история уровней, соотношение выполненного и пропущенного. |
| Дневник | Запись за любой прошедший день, оценка 1–10, поиск, редактирование, удаление. |
| Уведомления | Утреннее напоминание, рефлексия вечером, напоминания заданий, дедлайны, новый уровень, завершение миссии — каждое настраивается отдельно. |
| Настройки | Множитель XP, порог успешного дня, акцентный цвет, отключение анимаций, часовой пояс, первый день недели, экспорт JSON, выход и удаление аккаунта. |
| Адаптивность | < 600 px: нижняя навигация, одна колонка. ≥ 600 px: боковая навигация, 2–3 колонки, отдельные раскладки экранов для планшета. Ширина берётся из реально доступного места. |

## Архитектура

```
lib/
  app/        приложение, роутер, тема, GameConfig, env
  core/
    game/     игровой движок (чистый Dart, без I/O), каталоги, статистика, серии
    services/ уведомления, экспорт, защищённое хранение сессии
    widgets/  дизайн-система: карточки, кнопки, прогресс, состояния
    responsive/ брейкпоинты и адаптивные сетки
  data/
    models/       типизированные модели
    datasources/  Hive (локально) и Supabase (удалённо)
    repositories/ авторизация, синхронизация
  features/   экраны по разделам
supabase/migrations/  схема БД, RLS, серверные функции
test/                 тесты игровой механики и синхронизации
```

**Поток данных.** Каждое действие идёт через `GameEngine` и возвращает новое состояние, список изменённых строк и игровые события. Контроллер сохраняет строки в Hive, ставит их в очередь синхронизации и передаёт события в интерфейс (тосты, экран нового уровня, уведомления).

**Офлайн и синхронизация.** Приложение сначала пишет локально. Очередь отправляется при появлении сети, при возвращении в приложение и с экспоненциальной паузой после ошибок. Слияние: для изменяемых данных побеждает более новая запись, журнал XP/Gold объединяется. ID разовых наград детерминированы (UUID v5), поэтому два устройства, офлайн получившие одну и ту же награду, создают одну строку. Строки, отклонённые сервером, откладываются и не блокируют очередь.

**Защита на сервере.** Таблицы XP, Gold, выполнений, покупок и достижений клиенту доступны только на чтение. Запись идёт только через функцию `sync_ledger`, которая проверяет владельца, лимиты XP по сложности, одноразовость наград, баланс при покупке, уровень для награды за уровень и т. д. Открытие навыков проверяется триггером по очкам навыков, рассчитанным на сервере.

## Проверки

```bash
flutter analyze
flutter test
```

- `test/game_engine_test.dart` — 28 тестов: начисление XP, уровни, двойное выполнение, отмена, дневные лимиты, подзадачи без фарма, испытания, награды за уровень, наказания, отдых, уважительные причины, долгое отсутствие, перенос, магазин, навыки, серии, сериализация.
- `test/sync_merge_test.dart` — 5 тестов на слияние при синхронизации.
- SQL-миграция прогнана на локальном PostgreSQL 17 с имитацией схемы `auth` из Supabase: 16 сценариев (RLS, завышенный XP, повторная отправка, чужие данные, удаление аккаунта) дали ожидаемый результат.

## Шрифты

Шрифты Manrope и Cormorant Garamond встроены в приложение (`assets/fonts/`, лицензия SIL OFL 1.1, тексты лицензий лежат рядом и видны на экране лицензий). Загрузка шрифтов из интернета выключена (`GoogleFonts.config.allowRuntimeFetching = false`), поэтому оформление одинаковое и без сети, в том числе при самом первом запуске.

## iOS

Минимальная версия — iOS 13: этого требует `connectivity_plus` 7.x. Версия задана в `ios/Podfile`, `project.pbxproj` и `AppFrameworkInfo.plist`. Для сборки нужен Mac с Xcode:

```bash
flutter pub get
cd ios && pod install && cd ..
flutter run -d <iPhone>
```

Для публикации или установки на реальный iPhone нужен аккаунт Apple Developer и настроенная подпись (Signing & Capabilities в Xcode).

## Принятые решения

- **Миссии** хранятся в таблице `quests` (тип `main`/`boss`), а `missions` — представление поверх неё, чтобы не дублировать данные.
- **attributes** — представление, которое считает XP характеристик из журнала транзакций.
- Очки навыков: 1 за каждый уровень персонажа и 1 за каждый уровень любой характеристики.
- Сервер проверяет **размер** награды за достижение и её одноразовость, но не пересчитывает само условие достижения.
- Системные уведомления работают на Android и iOS; в web-версии настройки сохраняются, но уведомления не показываются.

## Известные ограничения

- Регистрация, вход и синхронизация проверены на уровне кода и SQL, но не на живом проекте Supabase: в этой среде его нет.
- Android: приложение собрано и запущено на эмуляторе Pixel 9 (Android 15), в том числе без сети.
- iOS: сборка на iPhone и в iOS-симуляторе не проверялась — для этого нужен Mac с Xcode. Интерфейс проверен в web-сборке на размерах iPhone SE (375×667), iPhone 16 Pro (393×852) и в альбомной ориентации (852×393). Особенности iOS (вырез, Dynamic Island, системные жесты) так проверить нельзя: в коде они учтены через `SafeArea`, но живой проверки не было.
- В пути проекта есть кириллица, а компилятор шейдеров Flutter (`impellerc`) не может писать в такой путь. Android-сборку запускайте с латинского пути, например через виртуальный диск:

  ```bash
  subst R: "C:\Users\user\Videos\программирование\RPG"
  ```

  затем `cd R:\` и `flutter run`. Отключить диск: `subst R: /d`.
- Android: Gradle 8.11.1, Android Gradle Plugin 8.9.1 (этого требуют текущие версии AndroidX). При нестабильной сети в `android/gradle.properties` увеличены таймауты и число повторов загрузки.
